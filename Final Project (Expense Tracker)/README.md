# Expense Tracker

A simple desktop app I made as the final project for my Python Vocational Training.

It helps you keep track of daily expenses using Tkinter and SQLite3.

## Features

- Add, update and delete expenses
- Choose expense categories
- View total spending
- Save data using SQLite3

## Built With

- Python
- Tkinter
- SQLite3
- PyInstaller

## Files

```text
Final Project/
├── Expense Tracker Final Project.py
├── Expense_Tracker.exe
└── README.md
```

## How to Run

**Windows:** Double-click `Expense_Tracker.exe`.

Or run the Python file:

```bash
python "Expense Tracker Final Project.py"
```

The `expenses.db` file is created automatically when the app runs.

This project helped me practice Python functions, GUI development, database handling, and basic CRUD operations.
